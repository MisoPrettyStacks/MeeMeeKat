## 🧠 The Predictive Mathematical Model

The engine tracks a token's momentum and decay using discrete summation formulas over simulated intervals ($t$):

$$\Delta m_t = \tau_k(t) \cdot \Big(1 - (\eta \cdot S(t))\Big)$$

$$m(t) = \max\Big(0, \, m(t-1) + \Delta m_t\Big)$$

*   **Temporal Mass ($m(t)$)**: The net calculated structural value of the token over a simulated 24-hour horizon.
*   **Instantaneous Coherence ($\tau_k$)**: Attention velocity, derived from **24h Buy Volume $\times \ln(\text{Total Buys})$**.
*   **Entropic Decay ($\eta \cdot S$)**: The value bleed parameter, computed from the **Sell-to-Buy ratio** and compounded by the interactive **Whale Concentration Risk Slider**.
